# 瑪奇M - 兼職小助手 v1.0.1

協助《瑪奇 Mobile》玩家領取兼職素材、逐一交付任務，以及盤點公用保管箱庫存。支援清單內 19 種任務，預設每種交付 3 次，共 57 次。

## 開始使用

1. 下載並解壓縮 ZIP，執行 `MabinogiAssistant.exe`。不需要安裝 Python 或 Excel。
2. 使用 Windows 10／11 64 位元，電腦需有 Windows PowerShell 5.1 與繁體中文（台灣）文字辨識元件。
3. 只開啟一個《瑪奇 Mobile》遊戲視窗，遊戲內容解析度設為 **1280 × 960**，並讓完整遊戲畫面留在螢幕內。
4. 建議將遊戲鏡頭改為**手動鏡頭**。

EXE 可以單獨執行；README 與更新紀錄供查閱，不必保留在 EXE 旁。首次啟動請稍候。

若提示缺少繁體中文文字辨識元件，需先在 Windows 安裝該元件，單獨下載 EXE 並不會自動安裝。可請電腦管理員依 [Microsoft 的 OCR 語言套件安裝說明](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor#install-an-ocr-language-pack) 操作，將範例語言 `en-US` 改為 `zh-TW`；不需要安裝 PowerToys。完成後重新開啟助手。

每次按下開始，助手會倒數並切回遊戲。作業期間請勿操作遊戲或切換其他視窗；需要操作時先暫停。

## 素材領取

**用途：**從公用保管箱領取清單內 19 種素材，每種固定領取足夠完成該任務 **3 次**的數量。

**開始前：**

- 在遊戲開啟 **公用保管箱 → 全部**。
- 關閉物品提示、數量輸入視窗及其他對話。
- 備妥各素材所需數量，並預留足夠背包負重。
- 同一素材請準備一堆足夠數量；助手不會合併不足的多堆疊。

切至「素材領取」分頁，按 **「開始／繼續領取」**。完成後查看清單；若有「待手動補領」，請依列出的素材與完整數量自行補齊。

領取量不會扣除背包已有素材，也不會跟著交付次數或盤點循環數改變。若遊戲限制可領取數量，助手可能仍標示已領取，請在交付前確認素材足夠。

## 任務交付

**用途：**依各任務的剩餘次數，逐張使用卷軸並交付；確認上一張完成後才處理下一張。

**開始前：**

- 自行移動到 **任務佈告欄旁**，關閉對話與物品詳細視窗。
- 背包內備妥所需卷軸與素材；不必先執行素材領取或庫存盤點。
- 確認現有佈告欄任務已顯示在追蹤欄。尚未完成或不在助手支援清單內的任務，請先自行處理；不要隱藏追蹤。
- 在「任務交付」分頁用每列 **「−／＋」**設定剩餘次數，預設 3，設為 0 可略過。增加次數時，請另外準備卷軸與素材。

按 **「開始／繼續交付」**。背包可以關閉，也可以停在材料頁；助手會切到任務分類。

- 若開始時已有可辨識且可回報的支援任務，會先完成它，並計入該任務次數。即使剩餘設為 0，已啟用的這一張仍會先完成。
- 找不到卷軸時，會略過該任務所有剩餘次數，保留已完成紀錄；略過不算完成。卷軸很多時，可先整理背包再試。
- 停止後可修改剩餘次數；執行中、有已啟用任務或有中斷結果待核對時，不能修改。
- 「採集卷軸：蜘蛛絲」使用的素材是**蜘蛛網**；素材等級與名稱中的 **＋**不能互相替代。

## 庫存盤點

**用途：**統計公用保管箱內的支援素材，顯示需求、已辨識庫存與缺額。**不包含背包，也不會領取素材或更動交付次數。**

**開始前：**

- 開啟 **公用保管箱 → 全部**，搜尋篩選也設為 **全部**。
- 關閉物品提示、數量輸入視窗與其他對話。

切至「庫存盤點」分頁，選擇 **1–6 個交付循環**，再按 **「盤點公用保管箱」**。1 循環代表每種任務 3 次；6 循環代表每種 18 次。

綠色列代表已辨識庫存足夠，紅色列代表目前辨識量不足。掃描未完成、畫面不清楚或清單無法捲動時，缺額可能高估，請查看完成狀態並人工核對。可按「複製盤點結果」保存表格；領取或整理庫存後，請重新盤點。

## 暫停、停止與重新開始

- **暫停／繼續：**預設按 **F8**，也可按助手的暫停按鈕。可在尚未執行時改為 F1–F12。手動暫停會保留目前步驟；暫停期間請勿改變遊戲頁面或手動轉移物品。
- **失去焦點或辨識不明：**助手會停止。查看「停止原因」，先恢復正確遊戲畫面，再按對應功能的開始按鈕。
- **中斷結果待核對：**先檢查遊戲內是否真的完成，再選「確認已成功」或「確認未發生」。無法確定時保持停止，避免重複領取或啟用任務。
- **重置：**停止工作後按「重置」建立新批次，恢復每種任務 3 次。這不會撤銷已領取素材或遊戲內已啟用的任務。
- **關閉重開：**每次啟動都會建立新批次，不會接續上一批；請先確認背包與現有任務，避免重複領取。

## 紀錄與使用限制

需要回報問題時，按「顯示除錯紀錄」，再用「複製全部」取得紀錄。設定、進度與報告只保存在本機 `%LOCALAPPDATA%\MabinogiSideHustle`，不會自動上傳；更換 EXE 不會刪除這些資料。

本版僅支援上述解析度與前景操作，不會自動移動到佈告欄，也不會計算背包剩餘負重。隱藏或未追蹤的任務可能無法被發現。完整 57 次連續交付及不同庫存排列尚未全面實機驗證，使用時請留意遊戲畫面與停止原因。
