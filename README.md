# Mabinogi Mobile Quest Assistant

Windows desktop assistant for 瑪奇 Mobile. Version 1 targets a 1280 × 960 game content area.

The first milestone is read-only capture and recognition preview, plus a separately triggered inventory-key compatibility test. Storage withdrawals and quest activation are not implemented in this milestone.

See AGENTS.md for the full project contract. Private reference media, the original workbook, local reports, and settings are excluded from Git. The default whitelist contains only game-reference data; original workbook metadata is not distributed.
